# Bandit Level 0

## Objective
Connect to the OverTheWire Bandit server using SSH.

## Command
```bash
ssh -p 2220 bandit0@bandit.labs.overthewire.org
```

## Steps
1. Open the terminal.
2. Run the SSH command.
3. Type `yes` when asked to verify the server's authenticity.
4. Enter the Level 0 password provided by OverTheWire.

## Result
Successfully connected to the Bandit server as `bandit0`.

## Key Learning
- **SSH:** A protocol used to securely access remote systems.
- **Port 2220:** The port used by the Bandit SSH server.
- **Host Key:** Helps verify the identity of the remote server.
